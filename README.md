## 🌟 About
ZeroTools is a completely free, client-side only toolbox designed for creators and developers. 

Tired of uploading sensitive images and PDFs to random backend servers? ZeroTools uses modern Web APIs (Canvas, FileReader, WebAssembly) to process your files locally. **Zero server uploads, zero limits, and 100% privacy guaranteed.**

## 🛠️ The 13 Tools Included
1. **Background Remover** (Powered by AI / WebAssembly)
2. **Image Compressor** (WebP, PNG, JPG)
3. **File Converter**
4. **PDF Compressor** (Local metadata stripping)
5. **Hashtag Generator**
6. **QR Code Generator**
7. **Password Generator**
8. **Color Palette Generator**
9. **Lorem Ipsum Generator**
10. **JSON Formatter & Validator**
11. **Word Counter**
12. **Base64 Encoder/Decoder**
13. **Case Converter**

## 🚀 How it works (The Tech Stack)
* **Framework:** React + Vite
* **AI Background Removal:** `@imgly/background-removal` (WASM runs locally in the browser)
* **Image Compression:** HTML5 Canvas API
* **PDF Optimization:** `pdf-lib`
* **Routing & SEO:** `react-router-dom` + `react-helmet-async`
* **Hosting:** Vercel

## 👨‍💻 Running Locally
If you want to run this toolbox locally on your machine:

```bash
# Clone the repository
git clone https://github.com/SEU_USUARIO/micro-saas.git

# Install dependencies
npm install

# Start the local development server
npm run dev
```

## 🛡️ Privacy Policy
This project operates on a strict zero-backend philosophy. No files, documents, or texts are ever transmitted over the network for processing. All logic is executed on your device's CPU/GPU.
